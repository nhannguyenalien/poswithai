📖 Tài liệu API

Gọi API bằng header xác thực, thay <token> bằng token đã tạo ở trên:

Authorization: Bearer <token>

Base URL: https://your-domain.pages.dev

Mọi request/response đều là JSON. Dữ liệu luôn giới hạn trong phạm vi cửa hàng (tenant) sở hữu token — không thể xem/sửa dữ liệu của cửa hàng khác.

Ví dụ lấy danh sách sản phẩm: 
curl -H "Authorization: Bearer pos_xxxx" https://your-domain.pages.dev/api/products

Tạo API token mới
Đặt tên để sau này biết token nào dùng cho việc gì — có thể thu hồi riêng từng cái bất cứ lúc nào.
Chặn spam/lạm dụng — vượt quá sẽ bị từ chối tạm thời (429) cho tới phút kế tiếp. Để 120 nếu không chắc.
✅ Token đã tạo — lưu lại ngay
Token chỉ hiện đúng 1 lần ngay bây giờ. Đóng cửa sổ này lại sẽ không xem lại được nữa — nếu quên phải thu hồi và tạo token mới.
