💾 Sao lưu & Khôi phục

Sao lưu toàn bộ dữ liệu (sản phẩm, khách hàng, đơn hàng, công nợ...) — tải về máy hoặc đẩy lên S3. Khôi phục lại được bất cứ lúc nào từ file đã lưu.

📥 Sao lưu

Xuất toàn bộ dữ liệu hiện tại thành 1 file JSON. Có thể dùng file này để khôi phục lại sau này.

📤 Khôi phục

Chọn 1 file backup (.json) đã tải trước đó để khôi phục lại. Dữ liệu trùng ID sẽ được cập nhật đè, dữ liệu mới sẽ được thêm vào — không xoá dữ liệu hiện có ngoài phạm vi file.

Lưu ý

  • Backup gồm: sản phẩm, kho hàng, khách hàng, công nợ, đơn hàng, thanh toán, hoá đơn vàng, mẫu hàng, danh mục, cài đặt...
  • Không gồm: tài khoản đăng nhập (users), API token (vì chỉ lưu bản băm, không khôi phục lại dùng được), nhật ký thao tác.
  • Sao lưu lên S3 cần cấu hình sẵn trên server (báo kỹ thuật nếu bấm nút mà báo "chưa cấu hình").
  • Nên tải về định kỳ (VD: cuối mỗi ngày/tuần) và lưu ở nơi an toàn.
